## Brand & Style

This design system expresses a high-velocity, premium urban mobility platform. Built for modern transportation and ride-hailing, the interface balances supreme reliability with an energetic pulse. It targets active urban commuters, executive passengers, and demanding drivers across bilingual Arabic-first and English-ready landscapes.

The visual style blends **High-Contrast / Bold** clarity with **Corporate / Modern** precision. A deep, authoritative Royal Indigo provides institutional stability, while high-voltage Electric Lime introduces speed, optimism, and dynamic movement. Layouts are strictly architected for primary Right-to-Left (RTL) reading flows without compromising Left-to-Right (LTR) parity. Surfaces feel crisp, hyper-legible under harsh outdoor daylight, and structured around rhythmic cards, tactile touch targets, and unmistakable navigational cues.

## Colors

The palette establishes a high-contrast chromatic duality:
- **Primary (`#1F0F8C`)**: Anchors critical interactions, brand identity, navigation backdrops, and confirmation actions.
- **Secondary (`#D3D93C`)**: Deployed strategically for promotional badges, pickup beacons, vehicle status highlights, and active micro-indicators. Never use with light text; always pair with `text-primary` (`#0F172A`) to ensure WCAG AAA accessibility.
- **Neutrals**: Built on a slate scale to keep the visual field balanced against the high-chroma primary. `#F6F8F9` serves as the canvas foundation, setting a luminous backdrop that lets pure white surfaces (`#FFFFFF`) pop forward naturally.
- **Semantic Feedback**: Structured as a rigid 3-tier matrix (`*-light` surface fills, `*` core graphic pins/icons, and `*-dark` high-legibility text and borders).

## Typography

The typography stack uses geometric, open-counter structures configured for high legibility across variable viewport resolutions and multi-script environments. When targeting Arabic runtimes, pair with `Cairo` matching equivalent weight and scale tiers.

- **Headlines**: Weighted strictly between `600` (SemiBold) and `700` (Bold) to project authority in booking flows, destination cards, and fare receipts. Tight negative tracking keeps larger scales cohesive.
- **Body & Controls**: Relies on weights `400` (Regular) and `500` (Medium). For numerals, prices, estimated time of arrival (ETA), and license plates, utilize tabular numeric figures to ensure vertical alignment in real-time ride tracking lists.
- **Bilingual Rhythms**: Arabic scripts inherently demand slightly taller vertical line-box clearing; line heights are standardized with a generous baseline to avoid diacritic clipping.

## Layout & Spacing

This design system uses a fluid-responsive column grid paired with an 8-point spatial cadence:
- **Mobile (390px - 430px)**: 4 columns, `gutter-mobile` (12px), `margin` (16px). Single-column stacked sheets, fixed bottom sheets for ride dispatch, and full-width card anchors.
- **Tablet (768px - 1024px)**: 8 columns, `gutter` (16px), `margin-tablet` (24px). Split master-detail view (map viewport pinned alongside interactive booking forms).
- **Desktop (1280px+)**: 12 columns, max-width container 1280px, `gutter-desktop` (24px), `margin-desktop` (40px). Side rails and modular dashboard layouts.

All interface spacing must use bidirectional CSS logical properties: `padding-inline-start`, `padding-inline-end`, `margin-inline-start`, and `margin-inline-end`. With the primary application environment set to `dir="rtl"`, starting edges align to the right side of the visual field.

## Elevation & Depth

Visual hierarchy is built through a combination of crisp container outlines and diffused ambient lighting. Rather than relying on muddy, multi-tiered dropshadows, the design system utilizes low-contrast borders combined with atmospheric surface elevation:

- **Level 0 (Flat Ground)**: Used by `background` (`#F6F8F9`) and inactive form surfaces. No shadow, 1px border using `divider` (`#EEF0F2`).
- **Level 1 (Cards & Tiles)**: Base interactive surfaces (`#FFFFFF`). Border: 1px solid `divider` (`#EEF0F2`). Shadow: `0 2px 8px -2px rgba(15, 23, 42, 0.04), 0 1px 4px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Floating Action Panels & Bottom Sheets)**: Ride confirmation bars, sticky search headers. Border: 1px solid `border` (`#E1E3E4`). Shadow: `0 8px 24px -4px rgba(31, 15, 140, 0.08), 0 4px 12px -2px rgba(15, 23, 42, 0.04)`. Note the subtle primary-indigo ambient tint that anchors moving layers to the core brand.
- **Level 3 (Modals & Critical Overlays)**: Driver arrival alerts, fare breakdown dialogues. Solid scrim using `text-primary` (`#0F172A`) set at 40% alpha, elevating the modal with shadow `0 20px 40px -8px rgba(15, 23, 42, 0.16)`.

## Shapes

The shape vocabulary employs a progressive corner radius scale calibrated around `roundedness: 2` (base 8px radius):
- **Micro-Controls (Inputs, Standard Buttons, Chips)**: 12px (`rounded-xl` in this configuration), offering a friendly yet structured tactile touch response.
- **Surface Cards & Modular Panels**: 16px (`rounded-2xl`), framing map excerpts, ride option selectors, and payment items.
- **Floating Overlays & Bottom Sheets**: Top-leading and top-trailing corners are rounded to 24px, conveying physical sliding sheet ergonomics.
- **Status Pills, Vehicle Class Badges, Avatar Rings**: Fully rounded pill shapes (9999px) to establish visual contrast against structural layout rectangles.

## Components

### Buttons
- **Primary**: Background `primary-500` (`#1F0F8C`), label `surface` (`#FFFFFF`). Hover: `primary-600` (`#190C70`). Active/Pressed: `primary-700` (`#130954`). Radius: 12px or full-pill for floating quick actions. Height: 48px on mobile, 44px on desktop.
- **Secondary (Accent Action)**: Background `secondary-500` (`#D3D93C`), label `text-primary` (`#0F172A`). Hover: `secondary-600` (`#B3B832`). Pressed: `secondary-700` (`#939728`). Used for instant booking confirmation, ETA callouts, and promotions.
- **Subtle Outline**: Background transparent, border 1px solid `border` (`#E1E3E4`), label `text-primary`. Hover: `surface-hover` (`#F8FAFB`).
- **Ghost**: Background transparent, label `text-secondary` (`#475569`). Hover: background `surface-subtle` (`#F4F6F7`), label `text-primary`.

### Input Fields & Search Bars
- **Container**: Fill `#FFFFFF`, border 1px solid `border` (`#E1E3E4`), border-radius 12px.
- **Typography**: Value in `text-primary`, placeholder in `text-tertiary` (`#71767F`).
- **Focus State**: Border color `primary-500`, accompanied by an outer halo ring `0 0 0 3px #E2E1F3` (`primary-50`).
- **Directional Iconography**: Search and location pin icons slot into the inline-start position (right side in RTL, left side in LTR). Clear buttons and destination swap toggles align inline-end.

### Cards & Ride Option Tiles
- **Default State**: Surface `#FFFFFF`, border 1px solid `divider` (`#EEF0F2`), corner radius 16px, Level 1 shadow.
- **Selected Ride State**: Border 2px solid `primary-500`, background `primary-50` (`#E2E1F3`) at 40% opacity or crisp `#FFFFFF`. Accompany with a check indicator in `primary-500`.

### Chips & Status Indicators
- **Filter Chips**: Fill `surface-subtle`, text `text-secondary`, border 1px solid `divider`. Selected: Fill `primary-500`, text `surface`. Radius: 9999px.
- **Status Badges**:
  - *Active Ride / En Route*: Container `secondary-100` (`#F3F5CB`), text `secondary-800` (`#73771E`), pulse dot `secondary-500`.
  - *Driver Arrived*: Container `success-light` (`#DCFCE7`), text `success-dark` (`#166534`).
  - *Cancelled*: Container `error-light` (`#FEE2E2`), text `error-dark` (`#991B1B`).

### Checkboxes, Radios & Switches
- **Radios (Ride Class Selector)**: 20px circle, 1.5px border `border`. Selected: 6px inner solid dot `primary-500` inside a 20px ring of `primary-500`.
- **Switches (Preferences & Toggles)**: Track 44px x 24px pill. Off: `border` (`#E1E3E4`). On: `primary-500` (`#1F0F8C`). Thumb 20px `#FFFFFF`, sliding cleanly from inline-start to inline-end.

### Lists & Activity Feeds
- **Separators**: 1px solid `divider` (`#EEF0F2`), inset by `16px` from inline edges.
- **List Item Interactive**: Base background transparent, hover `surface-hover` (`#F8FAFB`), active `surface-subtle` (`#F4F6F7`).
